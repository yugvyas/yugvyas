## 📖 Who I Am

I am a developer who believes that good software is built on strong fundamentals.
Rather than chasing tools blindly, I focus on understanding **why things work**,
how systems behave at scale, and how clean code improves long-term maintainability.

My interests span from **problem-solving and data structures** to **full-stack development**,
with a growing curiosity toward backend architecture and system design.
